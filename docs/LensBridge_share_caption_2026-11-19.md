# LensBridge — share caption

Meet **LensBridge** — connecting historical light to future discovery. ✨

I started this project with a question: how can observations we already have give future discoveries a longer history?

Today, our first three-observatory collection brings together **10,560 real measurements of one documented microlensing event**: 8,801 from OGLE, 1,745 from KMTNet and 14 published Spitzer measurements. Each keeps its source, original values and checksums, so the workflow can be inspected and repeated.

The aim is to build historical context for future Nancy Grace Roman Space Telescope science. This milestone is a verified data collection; calibration and scientific modeling come next.

**The who’s who:** project concept by Bart Salazar, developed with Brad Devowe through Simple Minds Studios. The observations and published reductions come from the scientific teams credited in the repository.

**And the AI?** Lincoln helped research sources, write code and documentation, and run the checks. Human curiosity set the direction; the saved evidence makes the work reviewable.

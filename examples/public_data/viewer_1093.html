LensBridge

One event. Three observing programs.

OGLE-2016-BLG-1093 / KMT-2016-BLG-1345. Explore the published magnitude measurements with a shared time axis and separate vertical scales. The plots retain each instrument’s values.

Run ogle_2016_blg_1093.py, then open its observations.csv here. The file is processed locally in your browser.

Magnitude increases downward: brighter measurements appear higher. Each panel chooses its own vertical range. A shared time origin does not establish a shared detailed time scale or photometric zero point. Points and error bars are published data, not a new model or calibrated joint fit. No file is uploaded or sent by this viewer.

# Published 1093 demonstration data

`1093.json` is a compact display derivative of the 10,728 published measurements in CDS/VizieR J/AJ/163/254/fig1, retrieved and verified by LensBridge. The original instrument labels, reduced HJD values, observed magnitudes, errors and original catalog record indices are retained as strings. The file records the source URL, original retrieval timestamp, source-response checksum and normalized-CSV checksum. Native time is HJD minus 2450000; the viewer adds that origin without cross-calibrating magnitudes.

Source: Shin et al. 2022, *OGLE-2016-BLG-1093Lb: A Sub-Jupiter-mass Spitzer Planet Located in the Galactic Bulge*, The Astronomical Journal 163, 254, DOI https://doi.org/10.3847/1538-3881/ac6513. Scientific contributors: OGLE, KMTNet, Spitzer and MOA. Catalog: CDS/VizieR, DOI https://doi.org/10.26093/cds/vizier.51630254, https://cdsarc.cds.unistra.fr/viz-bin/cat/J/AJ/163/254.

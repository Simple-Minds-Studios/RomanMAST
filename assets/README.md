# RomanMAST visual identity

`romanmast-banner.png` is AI-generated conceptual project artwork, commissioned for RomanMAST on 19 November 2026. Its cyan/violet lensing arcs and gold source point express the project theme; they are not observations, a calibrated diagram, or a mission logo.

`favicon.svg` is the matching small-format vector mark used by the project homepage. GitHub itself controls the icon shown on github.com; a repository favicon applies to its separately hosted site.

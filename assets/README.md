# LensBridge visual identity

`lensbridge-banner.png` is AI-generated conceptual project artwork, renamed from the RomanMAST banner for LensBridge on 19 November 2026. Its cyan/violet lensing arcs and gold source point express the project theme; they are not observations, a calibrated diagram, or a mission logo.

`favicon.svg` is the matching small-format vector mark used by the project homepage. GitHub itself controls the icon shown on github.com; a repository favicon applies to its separately hosted site.

Project attribution: Bart Salazar and Brad Devowe / Simple Minds Studios. See the root rights and attribution notice for applicable terms. The older root `RomanMAST.png` is retained as a historical asset and is not the active homepage banner.

The earlier `romanmast-banner.png` remains available for historical links. The active README and homepage use `lensbridge-banner.png`. The favicon geometry is retained, with its accessible title updated.
